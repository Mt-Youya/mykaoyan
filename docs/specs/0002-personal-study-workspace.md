# 规划 0002：由备考档案驱动的个人学习工作台

状态：部分实现。已完成本机备考草稿的三步选择、刷新恢复与按当前科目展示的个人工作台；报考目标可从研招网当前年度目录查找、带出科目、收藏并比较；英语科目的本机词表、单词复习与备份恢复已可用；试卷索引与专题编排留在浏览器；错题、复测与今日页使用登录保护的云端进度文档。公共课程、讲义仍只显示实际上架的数据。来源：站主要求增加背单词、试卷、错题、专题、学校模块，并提出先选择「学什么」「考哪套科目」「报哪个专业」再展示相应内容。站主已确认「22407」应为「22408」。保留已选新版 E 的视觉系统。本轮不部署、不 push。

## 产品主线

先建立一次备考档案，默认工作台只显示当前学习范围。考试科目、专业类别和学习工具分层组织，不把所有代码堆进首页导航。

- **报考目标**：招生年度、学校、学院、招生专业、研究方向、学习方式。未确定学校也可以开始。
- **考试组合**：目标所要求的完整初试科目，保存完整科目代码与名称。11408、22408 只是便于辨认的简称。
- **当前学习范围**：本阶段实际要学习的科目，是考试科目的子集；用户也可以先选择单科体验。完整考试要求仍保留在备考档案中。

复用现有备考档案，不另建一套重复的「备考方案」数据；界面可以用「我的备考」呈现其摘要。

## 首次使用与后续访问

1. 选择招生年度。已定目标者选择学校、学院与具体招生专业；没有定目标者跳过院校，直接选择考试组合。
2. 若目标有已核验的该年度招生目录，则带出考试科目，展示来源让考生确认；没有数据时由考生手动选择，不能猜。存在「或」选考项时，由考生明确选取。
3. 选择当前学习范围，例如「数学二、408」或「英语二、数学二、408」；未启用的考试科目保留在档案里，之后可以开启。
4. 进入工作台，显示今日页、对应课程与专题，以及适用的学习工具。后续访问沿用选择，无需重复填写。

访客可以先以本机草稿选择和浏览公共内容，不强制注册。登录后保存备考档案；私有题目、词表与答案仍按既有规则留在浏览器，不随档案上传。公共课程和讲义可直接访问，首次设置不能成为阅读内容的门禁。

## 模块如何随选择变化

| 模块 | 默认展示规则 | 最小实用范围 |
| --- | --- | --- |
| 今日页 | 有备考档案即可汇总，未开放的能力明确标状态 | 今日待办、复测、到期卡和学习时长；按现有顺序组织 |
| 课程与讲义 | 当前学习科目，以及该科目相关内容 | 科目目录、章、讲、讲稿、讲义；只显示已上架内容 |
| 背单词 | 当前有词汇学习需求时启用，例如英语一/英语二；允许手动开关 | 已实现：粘贴导入自有词条、新卡与到期卡复习、备份下载与恢复；不内置侵权词书 |
| 试卷 | 当前考试科目的试卷索引和本人导入的试卷 | 按科目/年份整理、官方来源、浏览器本地导入、做卷记录；不公开镜像真题正文与答案 |
| 错题 | 当前科目下本人的错题；按复测安排汇总 | 主动录入、关联考点、订正、复测与稳定；题目与答案为私有内容 |
| 专题 | 当前科目的专题，与目标考试范围匹配 | 围绕一组考点聚合课程、讲义、题目索引与本人错题入口，不重复复制内容 |
| 院校专业 | 当前报考目标优先；未定目标时提供查找 | 学校、学院、年度招生专业、考试科目、官方来源；收藏与并排对比 |

配置改变的是默认视图，不是数据所有权或权限。隐藏一个科目不会删除其错题、复习记录或学习记录。可以在「管理学习科目」里切回；旧档案也应可查看。

## 不同代码的归属

| 例子 | 层级 | 在产品中的用途 |
| --- | --- | --- |
| 101、201、204、301、302、408 | 考试科目代码 | 课程、试卷、考点与学习记录的科目依据 |
| 11408 | 英语一＋数学一＋408 的简称 | 预设选择；另保留政治等完整考试要求 |
| 22408 | 英语二＋数学二＋408 的简称 | 预设选择；不是专业名称 |
| 0854、0855、0856 | 专业学位类别：电子信息、机械、材料与化工 | 院校专业筛选的上层分类，不直接决定考试组合 |
| 085404 | 招生专业代码示例：计算机技术 | 与学校、学院、年度、方向、学习方式共同定位报考目标 |

不把专业代码与考试组合写死绑定。相同专业在不同学校、学院、方向或年度可能有不同考试要求。简称不作为唯一标识；混合数学/英语级别与自命题科目应优先完整显示，避免简称歧义。

统考科目可以跨学校复用。自命题科目不能只凭三位代码合并，应结合招生单位、年度与正式名称标识；两个学校的同号科目不能被当成同一门。

## 新版 E 的首页与导航

- **未配置**：保留新版 E 阅读气质，以「设置我的备考」为主要入口，同时提供「先浏览课程」。不先铺全国所有科目。
- **已配置**：首屏显示当前备考摘要，例如「2027招生／英语二、数学二、408／目标待定」，由真实档案生成，不显示示例账号数据。
- **公共导航**：课程与讲义、专题、试卷、院校专业。
- **我的学习**：今日页、背单词、错题、考点进度、每日记录；按当前学习范围与实际开放状态呈现。
- 顶部可进入「修改备考档案」。切换考试组合前展示科目差异，保留原始学习数据，不静默重置。

个人工作台的默认过滤不能代替接口权限控制。本人私有数据仍只能本人访问，未上架公共内容仍不可见。未实现模块不能先放一个看似可用的假入口。

## 学校模块的边界与来源

学校模块是对 v1 原有范围的新增规划。第一版只做官方招生目录与考试要求索引，不扩大成全国录取名单、分数线分析或录取概率预测系统。先维护少量有可核验来源的条目，再扩展覆盖。

每条招生记录至少带招生年度、适用学院/专业/方向/学习方式、来源 URL、核验日期与状态。缺失字段显示待核实，不用空白冒充确定信息。新年度目录不会自动覆盖上一年度，也不自动更改考生已确认的考试科目；变更应展示差异后由考生确认。

只引用来源与必要元数据，不转载官方公告原件、试卷正文、答案或真实考生名单。

## 研招网目录接入（2026-10-27）

数据来自研招网硕士专业目录的网页内部请求，没有官方文档，不是开放 API。`apps/api` 的 `admissions` 领域在服务端访问上游，串行限速、排队有上限、进程内缓存，上游失败时沿用旧结果并标明；页面只拿整理后的字段与研招网条目详情页链接。接口不属于公开契约，不提供任意地址转发。

上游的实际约束决定了选择顺序：

- **只有当前一个招生年度**（页面自述 `curYear`，2026-10-27 为 2027），没有年度参数。请求其他年度直接返回 409，不拿当前目录冒充；2026 及更早的目录需另找来源并单独标注年度。
- **顺序是学校 → 专业 → 招生条目 → 科目组**。上游没有学院列表，学院、方向与学习方式随招生条目出现，所以不能先选学院。
- **匿名每次只返回前 10 行**，第二页以 HTTP 200 返回「请登录」。招生单位的专业列表按代码排序，前 10 个多为哲学、经济等，计算机等专业通常不在其中。因此界面提供按学科类别缩小（四位代码，例如 0812、0854，对应上游 `yjxkdm`）与「输入六位专业代码」两条路径；截断以「共 N 个，只返回前 10 个」明示。本站不使用学信网账号或登录态绕过这一限制。
- **多个科目组是「或」关系**，由考生选定；管理类联考等后两位占位（`-`、`--`）不算科目。带出的科目仍需考生在下一步确认，手动改动目标或科目后来源随之清除。

2026-10-27 已对真实上游验收：年度、10 行上限（`pageSize=20` 仍为 10 行）、第二页「请登录」、「或」科目组、管理类联考占位与学科类别筛选均与实现一致，服务层输出与原始响应逐字段相同。浏览器中的选择流程同日走查通过；院校页支持本机收藏与两项并排比较，且保留来源链接。尚未完成：入库与定期刷新。

## 与现有里程碑的关系

1. **先整理入口与档案**：在现有登录和课程功能上补「目标—考试组合—学习范围」设置与个人导航，让数学二/408起步不再成为写死的全站限制。
2. **完成已有 M3 学习工具**：按原工单落实单词复习、错题复测、每日记录与今日页，再让工作台按档案显示。背单词和错题已有规划，不重复造领域。
3. **专题与试卷增量**：先做聚合索引、本地导入与个人记录的完整闭环，避免先搭没有内容的公开题库。
4. **院校专业增量**：先做少量核验条目、目标关联与比较，再考虑扩大学校/专业覆盖。0855、0856可以作为筛选结构，未有内容时不假装已提供相应课程。

本稿是产品与信息结构规划，不表示上述模块已实现。既有公开契约不在本轮直接改写；涉及备考档案新增字段时需在后续工单中处理兼容性与权限测试。

## 验收要点

- 选择数学二/408后，默认课程、专题、试卷与错题不混入其他科目；开启英语二后可以启用背单词。
- 目标未定仍可开始；已核验目标带出正确年度科目，专业代码本身不推导科目。
- 切换组合不丢失记录；隐藏科目可恢复查看；本人数据隔离不受筛选影响。
- 不出现无来源的招生断言、未上架内容、假数据或假功能入口。
- 试卷、错题、词表和答案的私有内容不会因建立备考档案而上传。
