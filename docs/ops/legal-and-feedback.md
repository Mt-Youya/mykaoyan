# 政策、出境告知与人工反馈（ticket 24）

## 公开入口

- `/privacy`：隐私政策，包含境外接收方、数据种类、目的、方式、存储地区与权利渠道。
- `/terms`：用户协议，包含内容规则、会员、审核、投稿授权与异议处理。
- `/support#report`、`/support#appeal`、`/support#privacy`：投诉举报、申诉、个人信息权利请求。全站页尾可达，无需登录或会员，独立于社区开关。

站主在本轮确认以「我的考研」为公开运营者名称，以 `feedback@mykaoyan.cn` 接收反馈。点击分类邮件入口只打开带说明的邮件草稿，用户仍须在邮箱发送；没有站内提交接口，不显示“已提交”或虚构编号。邮箱地址可直接选取或复制，复制失败有提示。

**收件尚未验收**：2026-10-30 系统 DNS 与公共 DNS 对主域 MX 查询均为 NOERROR、0 条回答。没有进行真实邮件投递，不保证该收件地址已经可用；需配置并验证邮箱服务、MX 与收件。没有修改 DNS 或发送邮件。

## 人工处理流程

1. 运营者检查公开收件箱，按投诉举报、申诉、个人信息请求分类。真实来信、联系方式、证明和处理台账保存在受控私有位置，禁止写进公开仓库、工单或日志。
2. 只收集定位记录和判断请求所必需的材料。账号类请求核验账号控制权，不通过公开评论收集手机号、验证码、完整证件，不向举报人披露被举报人的非必要信息。
3. 投诉举报：记录链接/编号、理由和必要线索；核对内容及版权、隐私风险，必要时先由管理员删除评论或下架投稿；保存操作记录，依法需要时向主管部门报告。
4. 申诉：对应原内容、原处置和补充材料复核，通过原邮件线程反馈结论或需补充事项；无法受理时说明理由。涉及恢复展示的操作仍受社区开关与其他外部条件限制。
5. 权利请求：核验后查阅/导出、更正或删除相应信息。注销或撤回相关同意时先撤销会话和 Agent 令牌，再按外键依赖与法定保留范围处理账号、学习、社区和对象数据；不能直接删除需保留的审计记录或其他账号的数据。对不能立即删除、需依法保留的情况说明理由并限制使用。备份恢复后重放已确认的删除请求。
6. 记录必要处置和反馈；材料不扩展用途，按最小必要和法定期限清理。定期复查邮箱可用性、待处理来信与紧急内容，不以页面已存在代表实际运营流程已跑通。

这些流程仍须由运营者实际执行；本轮没有收发真实投诉、执行真实账号注销或验证邮件送达，不冒充人工运营验收。

## 部署前后验证

本地交付不等于上线。另行授权部署时先应用新增列迁移、再部署匹配的 API 与网页；同步检查数据库和 R2 地区、政策正文版本与处理者联系信息。旧客户端缺少协议字段会被拒绝，须同时发布新登录页。

上线前按已核验的账号范围撤销旧版本会话与相关令牌，要求重新登录取得当前同意；本轮未撤销真实会话。仅修改政策常量不会使已有会话自动失效。

读回 API 的地区、版本和 `no-store`；匿名访问三页、页尾和分类锚点；确认两项勾选不预选、单独一项不能登录，旧版本被服务端拒绝。验证复制失败、邮件客户端未配置时的手工发送路径。真实邮箱、真实短信、浏览器与真机分别验收。

`COMMUNITY_ENABLED` 保持 false，备案、省内交互要求、视听业务资质和其他真实环境条件仍见[开放前核查](../delivery/community-launch-readiness.md)。本工单补入口不构成开放授权。
