# 会员期与兑换码（ticket 20）

登录后在登录页查看会员到期日、兑换及开通说明；管理员在“内容管理”的会员区输入待开通账号手机号与原因，开通一个365天会员期。账号已是会员时接在连续会员期最后，已过期时从开通时刻重新开始。日期按上海时间展示。

管理员生成完整兑换码后须立即连同编号保存，刷新页面后不可再次读取完整码。历史仅展示编号、末四位、是否兑换与兑换账号；编号用于区分末四位碰撞的码。兑换码不在数据库保存明文。不提供支付接入。

| 会话接口 | 行为 |
| --- | --- |
| GET /api/membership | 本人当前会员状态与连续会员期到期时刻 |
| POST /api/membership/redeem | `{code}`；为本人增加一期会员，重复兑换409 |
| POST /api/admin/membership/accounts | `{phone}` 精确查找，管理员权限，返回账号编号；手机号不放URL |
| POST /api/admin/membership/grants | `{accountId,reason}`；手动开通必须1–500字原因 |
| POST /api/admin/membership/codes | `{count}`，1–100；仅本次返回 `{codes:[{id,code}]}` |
| GET /api/admin/membership/codes?page=0 | 管理员按页查看记录，每页50个，含hasMore |

所有接口只使用网页会话，未登录401，已登录但无管理员权限403。管理员身份在服务层重新核对；进度和发布Agent令牌不用于会员管理。

开通与兑换独立可用。ticket 21–23已把评论的发表/回复、投稿/续传、评分入口接入会员判断与开通说明，并保留登录后的会员面板位置；社区默认关闭，见[评论说明](comments.md)、[投稿说明](submissions.md)和[评分说明](ratings.md)。

迁移仅在本地专用临时库重放验证，本轮没有推送到dev或prod。会员期起止、来源、原因及操作管理员被记录；兑换码消费和会员期写入同一事务。同账号所有开通途径先锁账号行，不同账号争同一码再锁兑换码行，配合唯一关联防止重复兑换。
