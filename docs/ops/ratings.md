# 评分与推荐（ticket 23）

现有考试科目页的投稿区显示评分人数、加权平均分和推荐标记，可按三位考试科目代码和考点筛选。列表始终按加权分降序排列，同分时优先评分人数更多的投稿。筛选只影响列表，不改变全站评分基准。

## 使用与权限

- 点击已上架投稿下的“评分”，会员会读回本人已有星数，可选择1–5星并保存；修改不会增加人数。自己的投稿会明确提示不能评分。
- 访客和非会员点击入口会看到手动开通、365天会员期和兑换码说明，链接到实际的`/login#membership`面板；会员到期后的评分修改同样由服务端拒绝。历史评分与人数保留。
- 与评论、投稿共用`COMMUNITY_ENABLED`，未设置默认false。关闭时不展示公开投稿和评分入口，直接请求评分读取或写入也不能绕过；本轮未开启真实社区。
- 管理员评分也须有有效会员期，不允许自评；管理员没有手动推荐入口。

## 得分口径

`m`为全站已上架投稿的全部评分均值，`C=10`，`n`为某投稿的评分人数。加权分为`(10*m+评分总和)/(10+n)`，全站无评分时m=0。一个投稿无人评分时加权分等于m，但不会推荐。

推荐须n≥5且精确加权分≥4.0。显示分数保留两位小数；标记不从显示值推断。修改评分、投稿上下架都会重算；下架投稿的历史评分不计入当前全站基准。相关决定见[ADR0014](../adr/0014-rating-aggregation.md)。

## 接口与数据

| 接口 | 行为 |
| --- | --- |
| GET /api/submissions?subject=302&topic=M01&page=0 | 公开已上架投稿，每页50条，先评分排序再分页；topic选填且须属于科目。新增ratingCount、weightedScore、recommended |
| GET /api/submissions/:id/rating | 网页会话下读取本人评分；返回stars（未评为null）及isOwn。不返回其他账号的评分明细 |
| PUT /api/submissions/:id/rating | 严格接收`{stars:1}`至`{stars:5}`，返回本人保存值；网页会话绑定身份，不能传accountId或recommended |

未登录401；非会员、到期会员、自评及关闭开关403；未上架、未通过、已清理或不存在投稿404；非法星数或额外字段400。GET与PUT均带no-store。网络结果不明时不自动重发，可重新打开评分读回核对。

`submission_ratings`以投稿/账号为组合主键，1–5星约束及更新时间落库；启用RLS并撤销PUBLIC、anon、authenticated权限。推荐不落库。迁移只在专用本地临时Postgres重放，本轮未迁移远程库或部署。
