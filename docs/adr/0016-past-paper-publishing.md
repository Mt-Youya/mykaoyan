# 站主取得授权后发布真题原文与答案，答案只对会员或上传者本人在单独页可见

站主于 2026-10-30 决定上线真题（含原文与答案），并明确授权后续由站主自行取得；风险与合规由运营者承担。此前 [PLAN.md](../PLAN.md) §1 与 §2.3 禁止转载真题原文与答案，本 ADR 记录该红线的变更及新的答案隔离方式。

## 决定

- 变更红线：真题原文、题图、真题答案可在站主确认取得授权后发布；未取得授权的真题内容不进入站点与仓库，官方公告原件仍不上站。SRC 读取限制放宽为「站主明确授权并指定的真题文本目录」。
- 内容结构化发布：试卷（科目、年份、来源说明）下逐题保存题号、题型、分值、题面、选项、答案、解析与考点；整卷与逐题都以 Markdown 保存，不发布原始 PDF/图片。
- 题面公开；答案与解析只在**会员或试卷上传者本人**可见的单独答案页（`/exams/{slug}/answers`），不进入题面页、列表、摘要、站内搜索、OG 卡片与 sitemap。管理员可直接查看。会员门与评论共用同一套会员期；上传者例外用于「用户自己上传的试卷/题目」。
- 发布仍只允许 `scope=publish` 的管理员令牌，默认下架；上架由管理员控制并写 `listing_changes` 审计。
- 授权与合规责任由运营者（站主）承担；本 ADR 不是法律意见，不声明「已获授权」。未取得授权前只建设发布链路，不导入真题内容。

## 取舍

答案页需要登录且要有效会员（或本人上传），公开分享会多一步；换来答案不会随题面索引到搜索引擎，也不会出现在公开页面摘要中。答案与题面同用 Markdown 而不是原始扫描件，牺牲了原卷版式，换取可检索、可结构化、可核查答案隔离；如以后需要原卷图片，需另立授权与存储方案。
