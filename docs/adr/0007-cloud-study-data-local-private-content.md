# 学习数据只存云端且必须登录，私有内容只留在浏览器

旧 kaoyan 支持匿名使用，为此写了浏览器存储、文件句柄回写和冲突处理的同步引擎，跨浏览器的降级路径从未测完。本站改为：访客只能浏览公开内容，学习追踪必须登录，学习数据只存云端，另外提供进度文件的上传和下载。词表、题目、答案等私有内容有版权或隐私问题，继续沿用旧 kaoyan ADR 0002：只在考生自己的浏览器里导入和使用，从不上传、从不进入构建产物或仓库；单词卡和复习记录也留在浏览器，靠备份文件迁移。

## Consequences

- 不移植旧 kaoyan 的同步引擎、文件句柄适配器和匿名数据迁移。
- 单词复习不能跨设备自动同步，这是有意的取舍。
