# 账号以手机号为准，第三方登录必须绑定手机号

《互联网跟帖评论服务管理规定》第四条要求评论用户完成真实身份认证，列举的方式是手机号、身份证号或统一社会信用代码；微信、QQ 登录本身不算。因此账号以一个已验证的手机号为准，v1 只提供手机号验证码登录（阿里云号码认证「短信认证」，个人实名即可开通，只支持 +86）。QQ、微信、支付宝登录等主体资质齐备后再加，加入后第一次用它们登录必须绑定手机号。不提供邮箱、Google、GitHub 登录。

## Considered Options

- **保留邮箱登录**：邮箱不满足评论实名要求，还要多维护一套发信。
- **Google、GitHub 登录**：大陆用户基本用不了。

## Consequences

- 账号表与登录方式表分开存，微信登录额外存 unionid，以后网页、App、小程序的微信登录能落到同一个账号。
- 绝不按手机号或邮箱以外的字段自动合并账号。
- 「短信认证」只能用系统赠送的签名和模板，两者必须配套，只能发 +86。
- 「短信认证」（号码认证服务 Dypnsapi）与「短信服务」（dysms）是两个产品。2025-06-06 起短信服务不再受理个人自用资质，2026-04-27 起不再支持基于 ICP 备案的网站类签名；这两份公告只针对短信服务，2026-10-26 复核时「短信认证」个人开发者页面仍写明免资质、免签名、免模板。风险：运营商政策可能延伸到「短信认证」。退路：注册个体工商户或公司后升级企业认证，用企业名申请签名改走短信服务。
