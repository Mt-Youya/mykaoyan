## 需要补齐的具体缺口

### 1. 备案、省内要求与视频业务范围

- 取得审批通过凭证，并在主页显著展示真实网站备案编号；按[部署运行手册](../ops/deploy-api-runbook.md)完成域名、HTTPS 和同源 API 验收。
- 咨询不能只问“个人博客能否评论”：需描述手机号登录、免费浏览、手动/兑换码会员、评论与回复、会员上传视频、人工审核上架、1–5 星评分与自动推荐，明确本阶段没有支付。
- 分别确认个人主体交互要求、评论新功能安全评估的适用性、视频投稿/自制课程所需业务资质。ICP 通过不自动覆盖视听业务；2010 年分类引用须按总局服务指南指向的 2017 年目录重核。尚无足以核销本站视频许可问题的证据。[视听管理规定](https://www.nrta.gov.cn/art/2007/12/29/art_1588_43750.html)、[审批指南](https://www.nrta.gov.cn/art/2018/11/4/art_3569_42384.html)。

可由站主向阿里云备案客服或对应主管部门发送的咨询提纲（本轮未发送）：

> 本站拟以个人主体提供免费的考研学习内容，无在线支付。使用手机号验证码登录，会员由管理员免费开通或兑换码获得；会员可评论一讲、回复一层、上传自制教学视频。视频经人工审核后上架，会员可给投稿评 1–5 星，系统按评分推荐。请确认本省个人备案是否允许这些业务、是否需要调整备案服务内容或主体；评论/评分是否涉及新功能安全评估；视频投稿与站主自制课程应向何部门核验哪些视听业务许可或备案。请分别说明条件、办理依据与业务限制。

### 2. 政策、协议及出境告知

- 登录页仍写“新加坡”，而生产[部署快照](../ops/current-deployment.md)写东京；本机配置也存在两个区域，不能凭本机变量推断线上实际连接。先读回部署环境的数据库区域及媒体处理位置，再统一政策、登录告知、评估与政策版本。当前 `PRIVACY_POLICY_VERSION` 为 `2026-10-27`；修订后应验证旧版本不能作为新注册的当前同意。
- [手机号出境评估](../privacy/pipia-phone-transfer.md)仍为草案，只覆盖早期登录活动。社区新增的评论、视频、评分和审计记录、Supabase 与 Cloudflare R2 的处理链路需纳入；受托处理者身份、境外接收方信息、保存位置、目的、期限与权利行使方式须核实。
- 确认处理者、公开联系渠道、查询/更正/删除与注销流程、撤回同意安排、保留期及备份处理；核实草案中的“30 天删除”等承诺确实可执行。没有自助注销不直接等于不允许上线，但人工渠道和处置能力必须落实。
- 用户协议需说明发布权限、禁止内容、投稿授权与版权、审核、下架、账号处置与申诉规则。两份全文应有稳定可达页面和登录/社区入口，不能仅靠一个出境勾选代替。
- 小规模出境豁免有适用前提，不豁免依法告知、单独同意和影响评估。需记录实际人数、是否含敏感信息/重要数据，并关注未满十四周岁用户的信息。依据：[跨境流动规定第五、七、八、十条](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)。

### 3. 投诉举报、申诉与审核运行

- 在 `apps/web/src`、`apps/api/src` 中未发现投诉举报、申诉或注销处理入口。当前关键词过滤、管理员删除评论/下架投稿与审计记录不能替代公众举报和被处置用户申诉。

- 明确日常巡查、违法内容处置与报告、账号处置和应急关闭职责；投稿需预览审核、核查版权及隐私，不能仅校验文件格式。依据：[跟帖评论服务管理规定第四、六、七、十三条](https://www.cac.gov.cn/2022-11/16/c_1670253725725039.htm)。第五条安全评估是否适用本站仍需外部确认。

## 核销与开放顺序

1. 补充备案、主体省份及咨询/业务资质结论；不满足允许开展的业务范围时先调整范围，保持关闭。
2. 核对真实数据链路，确认政策、协议、评估、联系渠道及处置规则，再实施政策页面、同意与投诉申诉入口。
3. 在另行授权的部署中完成迁移、配置和真实环境验收；开关先保持关闭，读回实际状态。
4. 其余条件逐项核销、ADR 更新且站主明确授权开放后，再开启 **同一个** `COMMUNITY_ENABLED` 并重启 API；读回评论、投稿、评分、非会员说明及管理员操作结果，验证回退路径。
