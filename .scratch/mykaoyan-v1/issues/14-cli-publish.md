## 实现与本地证据（2026-10-29）

### 发布链路

- API `POST /api/v1/publish/prepare` 接收公开契约的课程、章、讲与文件摘要，服务端计算内容哈希、分配不可覆盖的新对象 key，计划只属于当前账号。
- 预签名 S3 PUT 约束 Content-MD5、Content-Type、If-None-Match；对象上传后，`POST /api/v1/publish/:id/complete` 用 HEAD 核对大小、类型和单次 PUT 的 MD5 ETag，再写库。不支持用客户端任意 key 绕过上传。
- 发布用 `scope=publish` 专用 Agent 令牌，创建时与每次使用时都核对当前管理员角色；既有令牌默认 progress，不自动提权，不能相互代用。
- 新讲内容版本从 1 开始；相同内容哈希 prepare 不产生新版本、不签发新上传。课程级与讲级事务锁避免并发覆盖；过期内容基线返回 409。
- 所有新对象核对后登记，随后清理旧对象；SQL 更新不写 listed。删除失败准确报告 cleanupPending，并在重试完成或再次发布相同内容时恢复清理，不回滚新内容。
- 新课程/章/讲默认下架。章以课程内相对路径摘要建立 publish_key，不凭标题误合并旧章；路径重命名属于新身份，需要另行迁移策略。详见 ADR 0011。

### Rust CLI

`mykaoyan publish <章目录> [--dry-run]`，支持 --json；按已确认的“视频/字幕/讲稿”同名 mp4/srt/md 配对。只读取完整组合，跳过答案、解答、真题、answer、solution、M-P 标识及不完整组合；根目录答案条目也报告但不读取。符号链接拒绝读取。响应不打印签名 URL、令牌或讲稿原文。

真实 SRC 仅用于本地 dry-run，课程内容没有进入本仓库：数学二的“01-导数”识别 12 个完整组合；另 4 个字幕/讲稿无对应视频，报告跳过。没有对 SRC 或云资源写入。

### 验证

- 从空库重放全部迁移；新增发布计划 RLS、公开角色撤权、令牌默认 progress 均通过。
- 真实临时 Postgres + NestJS + 隔离 HTTP 对象服务，使用虚构账号和内容运行 Rust CLI：首次上传两个对象 → 完成登记/读回 → 重复发布无上传/版本不变 → 替换视频后重新上传/版本递增 → 旧 key 删除/新 key 全部可读，始终下架。R2 SDK 预签名的三个约束另有离线测试。
- 权限、角色撤销、吊销、服务层越权、未上传拒绝登记、并发201/409、删除失败恢复均覆盖。
- 变异检查：临时把发布守卫改认普通令牌、临时让内容更新写 listed=true，测试均按预期失败；恢复后通过。
- code-review 的 Standards 与 Spec 两轴发现均已修复并复核：权限不足403、旧讲空哈希契约、INT32边界、跨课程并发、清理恢复和根答案条目报告。OpenAPI 同步补齐403。
- 静态检查：pnpm fmt/lint/typecheck 通过；全仓库测试 664 项通过，有非阻断 lint 警告。Rust fmt/clippy 与10项集成测试通过；pnpm build 通过（媒体 Worker 仅 dry-run，未部署）。
- 浏览器 / 真机：跳过；生产上传/部署/云资源修改：未执行。

### 真实 R2 验收（2026-10-29）

站主补齐根 .env 后，五项 S3 配置存在且只读连接通过；凭据及账号、桶、端点值没有写进记录。使用隔离的本地 Postgres 重放全部迁移，真实 NestJS API 与 Rust CLI 连接已有的真实 R2 私有桶，未连接生产数据库、未部署 API。

| 项目 | 真实结果 |
| --- | --- |
| 小文件 PUT / HEAD | 视频与字幕直传成功，服务端大小、类型及 MD5 ETag 校验通过，完成登记并读回 |
| 替换与删除 | 新对象上传后版本从1到2；旧对象删除后 HEAD 均404，新对象存在，始终下架 |
| 已有 key 重复 PUT | 带签名的 If-None-Match 条件生效，R2 返回412，原对象保留 |
| SRC 一章 | 数学二“01-导数”12讲、24个视频/字幕对象全部存在，数据库每个 key 与桶中对象逐一核对；约452MiB视频 |
| 不完整配对 | 另4个字幕/讲稿缺少对应视频，按预期报告并跳过 |
| 整章重复发布 | 12讲全部 unchanged，版本仍为1；发布计划总数不增加，未新增上传；先下架再发布仍下架 |
| 收尾 | 按本次计划清单清理28个对象（含小文件替换的旧、新对象），HEAD逐一确认404；原有对象未纳入清理 |

本轮是验收发布，源课程目录只读；课程内容没有进入本仓库。临时数据库、虚构管理员和发布令牌随验收环境一并销毁。本轮未修改业务代码，未 commit、push、部署或创建桶/凭据。

线上 API 部署、浏览器/真机及媒体播放另行验收；中断发布计划的孤立对象自动清理仍未实现，运维需先核对引用和签名过期时间。
