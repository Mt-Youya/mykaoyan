# 20: 会员期与兑换码

**What to build:** 管理员可以给账号手动开通会员（必须写原因），或批量生成兑换码；考生兑换后获得一年会员，会员期可以叠加；页面显示到期日。

**Blocked by:** 08（管理员角色与上下架）

**Status:** ready-for-agent

- [ ] 会员判断与会员期叠加为纯函数，有测试（未过期续期、已过期再开、跨年）
- [ ] 不存「是否会员」字段，由会员期推算
- [ ] 兑换码一次性；兑换与生成会员期在同一事务里；并发兑换同一个码只有一个成功（测试）
- [ ] 管理员可查看兑换码是否已兑换、被谁兑换
- [ ] 非会员点击会员功能时看到开通说明
