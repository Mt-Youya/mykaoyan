# 33: 用户试卷前端（提交、社区题面/答案页、我的试卷、管理审核）

**What to build:** `apps/web` 新增用户试卷的提交页、社区列表、题面页与答案页、我的试卷，以及管理后台的试卷审核界面；与真题页面分开，答案页 `noindex`。

**Blocked by:** 32（API）

**Status:** ready-for-agent

**Spec:** [规划 0005](../../../docs/specs/0005-user-uploads.md)｜**ADR:** [0017](../../../docs/adr/0017-user-content-uploads.md)

- [ ] `/community/papers`：列表（科目筛选、标题、年份、题数、「用户投稿」标识），只列已通过上架；与 `/exams` 真题列表不混列
- [ ] `/community/papers/new`：逐题表单（题号、题型、分值、考点、题面、选项、答案、解析，可增删题）+ 可选 JSON 导入（浏览器用 `packages/core` 校验）+ 权利声明勾选 + 整卷字节数显示；提交成功显示待审核
- [ ] `/community/papers/$slug`：题面页（不含答案），底部答案入口按「未登录→登录、非会员→会员入口、上传者本人/管理员→直接进入」分流
- [ ] `/community/papers/$slug/answers`：答案页，逐题答案与解析，`noindex`；上传者本人可看自己试卷；未上架仅本人可预览（从我的试卷进入）
- [ ] 我的试卷：状态、驳回原因、题数、预览入口；未上架时明确提示
- [ ] `/exams` 增加「用户投稿试卷」说明/入口，但不混列、不改变真题行为
- [ ] 管理后台新增「用户试卷审核」：待审列表、完整预览（含答案）、通过/驳回（必填原因）、上下架切换与社区关闭提示
- [ ] 组件测试：表单校验与 JSON 导入、题面/答案页四种访问状态、`noindex` 标记、管理审核操作

**验收标准：** 登录账号可提交试卷并看到待审核状态；审核通过后社区页面可访问、答案页仅会员/本人/管理员可见；未上架/非会员/未登录状态提示正确；真题页面行为不变。

**红线：** 答案不出现在题面页、列表、OG、sitemap 或搜索；不把用户试卷混入真题列表；不写真实真题/答案内容（测试用虚构题目）。

**验收命令：**

```bash
pnpm --filter @mykaoyan/web test
pnpm typecheck && pnpm build
```
