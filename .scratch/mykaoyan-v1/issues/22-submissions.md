# 22: 投稿上传与审核

**What to build:** 会员上传一个 mp4 视频作为投稿，选择考试科目，可选考点；大文件分片直传、可断点续传；管理员审核通过后上架，驳回的文件 30 天后删除。

**Blocked by:** 04（媒体链路实测）、20（会员期与兑换码）

**Status:** ready-for-human（本地实现与浏览器验收完成；默认关闭，真实R2与真机待验收）

- [x] 上传前在浏览器校验格式（mp4、H.264）、大小（500MB）、时长（30 分钟）
- [x] 后端签发预签名分片上传，文件不经过 ECS；完成后读取对象元数据确认大小与类型再登记（本地替身与签名测试；真实桶待验收）
- [x] 投稿状态待审核 → 已通过 / 已驳回，驳回需写原因
- [x] 被驳回投稿的文件 30 天后删除：先写库标记，再删对象
- [x] 非会员调用上传接口返回 403
- [x] 投稿播放复用讲的播放令牌机制

## 本轮实现与验证（2026-10-30）

- core/submissions定义mp4/H.264、500,000,000字节、1800秒、科目与考点归属规则和8 MiB固定分片。浏览器读取实际容器的视频轨道与时长、逐片计算文件指纹，支持暂停和刷新后选择原文件续传。
- 投稿元数据RLS与公开角色撤权；对象key和R2上传编号由服务器保存，客户端不能指定。逐步复查当前会员与社区开关；分片/对象完成以R2列表和HEAD为准。对象完成而响应丢失时可重试登记。
- 待审核仅本人和管理员预览；通过时保留审核管理员和时间，开放社区才上架，驳回必须原因。上下架与追加审计同事务，管理页回读最近操作。过期会员不能继续上传，历史记录保留。
- 生产API启动时及每小时清理一批50条满30天的驳回文件，先持久标记再删对象，失败轮转重试；51条记录的测试验证前50条持续失败不阻塞后续文件。管理员可手动重试，记录不删除。
- 现有科目页和内容管理页接入真实投稿、续传与审核入口；复用会员开通说明和`/login#membership`路径。与评论共用默认关闭的COMMUNITY_ENABLED，关闭时公开列表、访客新播放令牌和全部上传步骤均不可用；真实环境仍待ticket24。
- 静态检查：格式、lint、所有包类型检查通过（含非阻断警告）。全量904项Vitest、13项Node通过，2项Windows分支跳过。文件大小上限的变异被测试检出，恢复后通过。
- 构建：所有包通过；Worker仅dry-run。首次dry-run输出结束后进程未退出，中断后以本次命令`WRANGLER_SEND_METRICS=false CI=1`重跑完整构建通过，未改全局配置。
- 本地运行：专用真实临时Postgres、模拟短信与R2替身；7项投稿HTTP及签名测试覆盖关闭、权限/归属、续传、元数据核验、完成重试、审核、审计、会员过期、清理与失败轮转。媒体播放经过实际Worker源码及本地桶替身。
- 浏览器：访客/非会员开通说明与登录后的会员面板、空白标题修正、第二片模拟断开、刷新续传待审核、审核上架、上下架审计、访客实际播放合成H.264视频、社区关闭时隐藏入口与内容均通过。
- 真实R2/CORS、线上上传与播放、真实清理任务和真机跳过，不算通过。未提交媒体文件、未读取SRC资料。
- code-review：Spec无遗留发现；Standards无遗留硬违反，权限辅助服务聚合基础设施的维护性建议本轮保留现有规模，不扩展重构。说明见`docs/ops/submissions.md`，取舍见ADR0013。
