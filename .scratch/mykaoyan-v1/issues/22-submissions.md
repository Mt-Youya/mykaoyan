# 22: 投稿上传与审核

**What to build:** 会员上传一个 mp4 视频作为投稿，选择考试科目，可选考点；大文件分片直传、可断点续传；管理员审核通过后上架，驳回的文件 30 天后删除。

**Blocked by:** 04（媒体链路实测）、20（会员期与兑换码）

**Status:** ready-for-agent

- [ ] 上传前在浏览器校验格式（mp4、H.264）、大小（500MB）、时长（30 分钟）
- [ ] 后端签发预签名分片上传，文件不经过 ECS；完成后读取对象元数据确认大小与类型再登记
- [ ] 投稿状态待审核 → 已通过 / 已驳回，驳回需写原因
- [ ] 被驳回投稿的文件 30 天后删除：先写库标记，再删对象
- [ ] 非会员调用上传接口返回 403
- [ ] 投稿播放复用讲的播放令牌机制
