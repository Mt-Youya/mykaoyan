# 24: 社区上线前的合规检查

**What to build:** 评论和投稿在确认合规条件后才对用户开放。

**Blocked by:** 21（评论）、22（投稿上传与审核）；外部条件：ICP 备案通过

**Status:** ready-for-agent

- [ ] ICP 备案（个人主体）已通过（外部前置条件，交付报告附备案号）
- [ ] 已向阿里云备案客服或当地通信管理局确认本省对个人备案网站开放评论与投稿的要求，结论写进 ADR 0005
- [ ] 隐私政策与用户协议定稿并上线
- [ ] 评论与投稿入口由一个配置开关控制，默认关闭；确认后再打开
- [ ] 上线前复核 ADR 0005 列出的条款
