# 17: 每日记录与今日页

**What to build:** 考生写或补录每日记录；打开今日页看到今天的计划分钟、要做的复测、到期卡和新卡数量、已记录的学习时长，按固定顺序排列。

**Blocked by:** 15（错题与复测）、16（备考档案与按天计划）

**Status:** ready-for-agent

- [ ] 每天最多一条每日记录，选已有日期时进入编辑
- [ ] 学习时长只来自每日记录
- [ ] 今日页排序为纯函数：逾期复测（逾期最久在前）→ 今天的复测 → 到期卡 → 新卡，有测试
- [ ] 到期卡与新卡数量来自浏览器本地的单词数据；本地没有词表时显示 0
- [ ] 今日页不替考生挑选考点
