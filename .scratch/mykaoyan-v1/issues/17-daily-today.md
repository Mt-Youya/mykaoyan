# 17: 每日记录与今日页

**What to build:** 考生写或补录每日记录；打开今日页看到今天的计划分钟、要做的复测、到期卡和新卡数量、已记录的学习时长，按固定顺序排列。

**Blocked by:** 15（错题与复测）、16（备考档案与按天计划）

**Status:** ready-for-human（本地完成并做过浏览器实测；真实 API 与线上验收待环境）

- [x] 每天最多一条每日记录，选已有日期时进入编辑
- [x] 学习时长只来自每日记录
- [x] 今日页排序为纯函数：逾期复测（逾期最久在前）→ 今天的复测 → 到期卡 → 新卡，有测试
- [x] 到期卡与新卡数量来自浏览器本地的单词数据；本地没有词表时显示 0
- [x] 今日页不替考生挑选考点

## Comments

### 2026-10-29：M3 落地

- `packages/core/src/daily/index.ts`：`upsertDailyLog`（同日期替换、否则追加，不改入参）、`getDailyLog`、`getRecordedMinutes`；页面只从每日记录读学习时长。
- `packages/core/src/today/index.ts`：`getTodayTasks` 输出固定顺序的待办（逾期复测 → 今天复测 → 到期卡 → 新卡，数量为 0 的条目省略），页面只做渲染；不返回任何考点建议。
- 今日页重写：显示当天各科计划分钟、弹性时间、`otherMin`、已记录分钟与「记录今天的学习」入口；无档案时提示先建档案。单词卡数量来自浏览器本地词表，页面注明本地无词表时为 0。
- 新增 `/daily` 页面：日期选择，已有记录时进入编辑并提示会覆盖；补录过去日期；最近 14 天列表可点回编辑。
- 每日记录上限由 `upsertDailyLog` 保证；进度文件本身仍允许 agent 上传同日期多条，页面按日期取第一条，写入时归并。

验证：core daily 3 项、today 4 项；web 今日页 SSR 3 项、每日记录页 SSR 3 项；浏览器实测：今日页按顺序展示、`/daily` 保存后 revision 2→3 且刷新显示「修改已有记录」。

遗留：真实 API + Postgres 未在本机跑，线上验收待部署。
