# 31: 课程材料前端（上传形态、手稿阅读、字幕轨、登录即可上传）

**What to build:** `apps/web` 的投稿面板与上传表单支持视频/手稿两种形态与视频字幕；手稿阅读、播放器字幕轨、我的投稿按形态展示；上传入口改为「登录即可」，不再用会员门。

**Blocked by:** 30（API）、27（投稿评论前端可并行依赖）

**Status:** ready-for-human（2026-10-31 本机实现；`pnpm --filter @mykaoyan/web test`（29 个文件、111 项）、`typecheck`、`build` 通过；新增投稿纯函数测试覆盖入口状态、手稿边界、字幕预检/条数、字幕编辑条件与清理提示。未做浏览器实测与真机实测，待 Lead 验收。）

**Spec:** [规划 0005](../../../docs/specs/0005-user-uploads.md)｜**ADR:** [0017](../../../docs/adr/0017-user-content-uploads.md)

- [x] 上传入口：访客显示登录引导；任何登录账号（含非会员）都能打开上传表单；`MembershipAction` 只用于评论、评分、看答案，不再包裹投稿入口
- [x] 表单形态切换：视频（现有字段）+ 可选字幕管理（≤ 2 条、语言/显示名、SRT/VTT 文件读取、客户端预校验、审核前可改）；手稿（标题、简介、科目、可选考点、Markdown 编辑区、字符计数、预览、提交）
- [x] 投稿卡片：`kind` 标签；视频保留播放器与字幕轨（`<track>` 指向 API 同源地址）；手稿「阅读手稿」展开区复用 `Markdown` 组件（不加载远程图片）
- [x] 「我的投稿」：形态、状态、驳回原因、字幕数量、手稿字节数、清理状态；续传只对 `uploading` 的视频显示
- [x] 权限提示：非会员上传不被拦截；本人内容显示「本人上传」与免会员评论入口；会员到期提示只出现在评论/评分/答案
- [x] 组件测试：登录/访客入口状态、手稿表单校验、字幕列表增删与超限提示、手稿渲染、清理状态展示
- [x] 移动端与可访问性：按钮 `min-h-11`、表单标签、错误提示 `role="alert"`，沿用现有样式

**验收标准：** 非会员登录后能完成手稿提交与视频投稿（含字幕）；访客被引导登录；手稿可阅读、字幕后可播放；我的投稿状态准确；只改 `apps/web` 与必要测试，不动 API。

**红线：** 前端只做上传前校验，不代替服务端校验；答案类内容不进入任何公开页面；不引入新的 Markdown/渲染依赖；不写真实内容。

**验收命令：**

```bash
pnpm --filter @mykaoyan/web test
pnpm typecheck && pnpm build
```
