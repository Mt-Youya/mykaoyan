# 23: 评分与推荐

**What to build:** 会员给已上架投稿打 1 到 5 星并可修改；不能评自己的投稿；投稿按贝叶斯平均排序，评分人数和得分达到门槛的成为推荐；可以按科目和考点筛选。

**Blocked by:** 22（投稿上传与审核）

**Status:** ready-for-human（本地实现、测试与浏览器验收完成；默认关闭，线上与真机待验收）

- [x] 贝叶斯平均与推荐判断为纯函数：`(C × m + Σ评分) / (C + n)`，`C = 10`，推荐门槛 `n ≥ 5` 且得分 ≥ 4.0，有测试
- [x] 每人每投稿一个评分；给自己的投稿评分返回 403
- [x] 非会员评分返回 403
- [x] 列表显示评分人数与加权平均分
- [x] 推荐不能手动设定

## 本轮实现与验证（2026-10-30）

- core/ratings为纯函数，固定C=10、人数至少5且未舍入得分至少4.0；严格星数输入不接受身份或推荐字段。全站无评分时m=0，m按当前已上架投稿的全部评分计算。
- submission_ratings开启RLS并撤销公开角色权限；投稿/账号组合主键保证一人一票，upsert支持修改与并发更新，写后核验返回值。不保存推荐标志。
- 服务使用网页会话本人身份，每次确认会员期与共享社区开关；管理员也需要会员期且不能自评。持投稿行锁确认上架状态后写入，与下架串行化；待审核、下架、已清理投稿不能评分。
- 公开列表在一次SQL查询中先聚合全站基准，再按科目/考点筛选和评分排序，最后分页。同分按人数、创建时间、编号降序；下架评分不计入基准，会员到期历史票继续保留。
- 现有投稿列表显示人数、加权分和推荐标记，加入科目/考点筛选及真实评分/修改表单。访客与非会员点击评分时显示手动开通、365天会员期与兑换码说明，进入实际会员面板。与评论、投稿共用默认关闭的COMMUNITY_ENABLED，关闭时入口隐藏且API评分读写拒绝。
- 静态检查：格式、lint、所有包类型检查通过（有非阻断警告）。全量929项Vitest、13项Node通过，2项Windows分支跳过。所有包构建通过，Worker仅dry-run；本次命令关闭Wrangler遥测，不改全局配置。
